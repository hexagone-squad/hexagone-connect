# Codebase Map

## Important Directories

| Path | Purpose |
| --- | --- |
| `apps/` | App workspaces. Current files are placeholders that export app names only. |
| `services/` | Domain service workspaces. `work-management`, `identity-tenant`, and `ai-orchestration` contain real behavior today. |
| `packages/` | Shared package workspaces. Keep shared code small and stable. |
| `contracts/openapi/` | Canonical versioned OpenAPI documents. |
| `contracts/events/` | Canonical versioned event schemas. |
| `ai/` | AI input/output types, guardrail policy, and evaluation fixtures. |
| `database/migrations/` | SQL migration drafts. |
| `scripts/` | Validation, governance, license, test-mapping, and Implementation Loop scripts. |
| `tests/` | Repository-level architecture, contract, and governance tests. |
| `.github/instructions/` | Path-scoped agent and review rules. |
| `policies/` | Machine-readable policies consumed by scripts. |

## Entry Points

| Path | Use |
| --- | --- |
| `package.json` | Root command surface. |
| `scripts/run-ci.ts` | Deterministic validation sequence for `pnpm run validate`. |
| `services/work-management/src/composition-root.ts` | Work-management use-case wiring for tests and callers. |
| `services/identity-tenant/src/authorization.ts` | Tenant access assertion helper. |
| `services/ai-orchestration/src/inspection-assistant.ts` | Inspection assistant orchestration entry point. |

## Generated Or Machine-Managed Files

- `pnpm-lock.yaml` is generated by pnpm; update it with pnpm commands, not manual edits.
- `node_modules/`, `dist/`, `build/`, and `coverage/` are generated and ignored.
- `evidence/implementation-loop/manifest.json` is generated per non-trivial change when Git metadata is available.

## Do Not Edit Directly

- Do not hand-edit `pnpm-lock.yaml`.
- Do not edit generated build, coverage, or dependency directories.
- Do not add service-local OpenAPI files; use `contracts/openapi/`.
- Do not commit `.env` files or secrets.

## Where To Add Functionality

| Change | Add it here |
| --- | --- |
| Work request business rule | `services/work-management/src/domain/` plus focused tests. |
| Work-management use case | `services/work-management/src/application/` plus tests under `services/work-management/test/`. |
| Work-management adapter | `services/work-management/src/infrastructure/` after defining an application port. |
| Tenant authorization behavior | `services/identity-tenant/src/` plus `services/identity-tenant/test/`. |
| AI inspection assistant behavior | `services/ai-orchestration/src/`, `ai/`, and AI tests/evaluations. |
| Public API shape | `contracts/openapi/` plus contract validation tests. |
| Event shape | `contracts/events/` plus contract validation tests. |
| Repository validation rule | `scripts/` plus a test under `tests/governance/` or `tests/architecture/`. |
| App UI | The owning `apps/*` workspace, after adding UI runtime and tests. |
